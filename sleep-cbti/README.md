# 好眠六週：失眠認知行為治療（CBT-I）自助工具

一個單頁網頁 App，照 CBT-I 標準流程帶使用者做六週的失眠治療。不用安裝，Android 用 Chrome 打開後選「加到主畫面」就能當 App 用。

> 這不是醫療器材，也沒有經過臨床試驗驗證。內容依照公開的臨床指引與研究設計，不能取代醫師的診斷與治療。

## 為什麼選 CBT-I

| 依據 | 結論 |
|---|---|
| AASM 臨床指引（Edinger 等，*J Clin Sleep Med* 2021） | CBT-I 是慢性失眠的**強烈建議**治療。睡眠限制、刺激控制、放鬆訓練單獨使用也有效（有條件建議）；單靠睡眠衛生**不建議**。 |
| 統合分析（Trauer 等，*Ann Intern Med* 2015，20 篇 RCT） | 入睡時間縮短約 19 分鐘、夜醒時間減少約 26 分鐘、睡眠效率提高約 10 個百分點，治療結束後效果仍維持。 |
| 數位 CBT-I RCT（Ritterband 等，*JAMA Psychiatry* 2017，n=303；Espie 等，*JAMA Psychiatry* 2019，n=1,711） | 網路或 App 形式的 CBT-I 同樣有效，效果維持到一年追蹤。 |

## 功能與設計依據

| 功能 | 做法 | 依據 |
|---|---|---|
| 安全篩檢 | 雙極性疾患、癲癇、異睡症、跌倒風險、高警覺職業、未治療的睡眠呼吸中止，符合任一項就**不啟用睡眠限制**，改用溫和版。另外問自傷念頭，有的話顯示台灣求助專線。 | Kyle 等（*Sleep* 2014）證實睡眠限制初期會增加嗜睡、降低警覺 |
| 呼吸中止風險 | STOP-Bang 8 題，≥3 分建議先做睡眠檢查 | Chung 等（*Anesthesiology* 2008） |
| 睡眠日記 | 上床、關燈、入睡分鐘、夜醒次數與分鐘、最後醒來、下床、品質、小睡、咖啡因／酒精／藥物 | Consensus Sleep Diary（Carney 等，*Sleep* 2012） |
| 第一個睡眠時段 | 基線 7 晚的平均實際睡眠時間，取最接近的 15 分鐘，下限 5.5 小時 | Spielman 等（*Sleep* 1987）。臨床常用下限 5 小時，本工具沒有醫師監督，所以用較保守的 5.5 小時 |
| 每週調整 | 最近一週（至少 5 晚）平均睡眠效率 ≥90% 延長 15 分、85–90% 維持、<85% 縮短 15 分。65 歲以上改用 85%／80% 門檻。 | 標準睡眠限制調整規則 |
| 刺激控制 | Bootzin 六條規則 | AASM 2021 |
| 放鬆訓練 | 慢呼吸節拍器（吸 4 秒、吐 6 秒，5 分鐘）、漸進式肌肉放鬆 | AASM 2021 |
| 想法調整 | 常見失眠信念與替代想法、想法紀錄、擔憂時間 | Harvey 2002；Carney & Waters 2006 |
| 睡眠衛生 | 照光、咖啡因、酒精、睡前熱水澡（40–42°C，睡前 1–2 小時） | Haghayegh 等（*Sleep Med Rev* 2019） |
| 趨勢 | 每晚睡眠效率圖（含調整門檻）、仿紙本睡眠日誌的時間軸圖、每週摘要、時段調整紀錄 | |
| 匯出 | CSV（Excel 可直接開，給醫師看）與 JSON 備份；可匯入 JSON | |

## 檔案

- `app.html`：原始碼，claude.ai Artifact 頁面格式。在 Artifact 裡開啟時，資料存在使用者帳號底下的私人空間（`data/users/<id>/`），只有本人看得到。
- `index.html`：由 `build.py` 產生的一般網頁版，資料存在瀏覽器的 localStorage。
- `build.py`：修改 `app.html` 後執行 `python3 sleep-cbti/build.py` 重新產生 `index.html`。

## 在手機上使用

1. 把 `index.html` 放到任何靜態網站，例如在 repo 設定開啟 GitHub Pages，網址會是 `https://<帳號>.github.io/<repo>/sleep-cbti/`。
2. 用 Android Chrome 打開，選單 →「加到主畫面」。
3. 資料只存在這支手機的瀏覽器裡，請定期在「設定」匯出備份。
